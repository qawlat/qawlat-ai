# بيانات قَولات للمطوّرين

قَولات تنشر تحليلها لجذور القرءان بياناتٍ مفتوحة برخصة **CC BY 4.0**. التحليل مبنيّ من نصّ القرءان وحده (رواية حفص)، بلا تفسير ولا معاجم خارجيّة. هذه المهارة تعين على اختيار المصدر وربطه بالمشروع.

## اختر الطريق

| الحاجة | الطريق |
|---|---|
| مساعدٌ ذكيّ يجيب أسئلة المستخدمين | خادم MCP: `https://qawlat.com/mcp` (أدوات جاهزة، بلا حساب) |
| تطبيقٌ أو موقعٌ يعرض البيانات | نزّل الملفّات من `https://qawlat.com/resources/` واحزمها مع التطبيق |
| بحثٌ أو تحليلٌ إحصائيّ | الملفّات نفسها، فهي كاملة |

🔴 الملفّات لا ترسل ترويسة CORS: لا تجلبها من متصفّح المستخدم مباشرةً. نزّلها عند البناء، أو اجلبها من خادمك.

🔴 لا تعتمد على مسارات `/data/mcp/`: هي داخليّة للخادم وتتغيّر بلا إشعار. العقد العامّ هو ملفّات `/resources/` وأدوات MCP.

## الملفّات

كلّها تحت `https://qawlat.com/data/<الملفّ>`. القائمة الحيّة وأحجامها وتواريخ تحديثها في `/resources/` (ومعها JSON-LD من نوع Dataset).

| الملفّ | ما فيه | البنية |
|---|---|---|
| `quran-full.json` | نصّ القرءان بالرسم العثمانيّ | `{ "<رقم السورة>": { "n": اسم, "a": [ { "t": نصّ الآية, "j": الجزء, "p": الصفحة } ] } }` |
| `data.json` | جدول المواضع: كلّ كلمةٍ قرءانيّة بجذرها وموضعها | `{ "suras": [...], "rows": [ { "r": الجذر, "sn": رقم السورة, "wt": الكلمة مشكولة, ... } ] }` |
| `words-stats.json` | صيغ الكلمات وعدد ورود كلٍّ منها | `{ "<الكلمة>": { "c": العدد, "root": الجذر, "alts": [...] } }` |
| `roots-stats.json` | لكلّ جذر: مجموع وروده وصيغه | `{ "<الجذر>": { "c": المجموع, "words": [ { "w", "c" } ] } }` |
| `roots-analysis.json` | التحليل الكامل لكلّ جذر (الأكبر حجمًا: عشرات الميغابايت) | `{ "<الجذر>": { "root", "field", "sections": [ ... ] } }` |
| `abwab-data.json` | أبواب الفعل (الأوزان) وشواهدها | |
| `fields-data.json` · `field-compare.json` | الحقول الدلاليّة ومقارنات جذور كلّ حقل | |
| `antonym-index.json` · `antonyms-data.json` | أزواج التقابل والأضداد وتحليلها | |
| `surahs-data.json` | ملفّ كلّ سورة: إحصاء وجذور وحقول ولطائف | |
| `topics-index.json` · `topics-data.json` | موضوعات القرءان وآياتها | |
| `asma-data.json` · `duas-data.json` · `discoveries-data.json` | أسماء الله وصفاته · أدعية القرءان · الاكتشافات البنيويّة | |

أقسام الجذر في `roots-analysis.json` (كلّ عنصرٍ في `sections` يحمل مفتاح قسمه): `concept` التعريف · `summary` الخلاصة · `verse` · `derivations` الاشتقاقات · `occurrences` المواضع · `common` · `distinction` و`distinctions` الفروق · `substitution` اختبار الاستبدال · `field_rel` علاقات الحقل · `antonym` التقابل · `shawahid` الشواهد · `lataif` اللطائف · `methodology` · `result` · `final`.

الحقول التي لم تُشرح بنيتها أعلاه: افتح الملفّ واقرأ مفاتيح أوّل عنصر قبل أن تبني عليه. والحقول التي تبدأ بشرطة سفليّة (`_codex_review` وأمثالها) داخليّة؛ لا تعرضها.

## القواعد

| القاعدة | التطبيق |
|---|---|
| لا أعداد ثابتة | عدد الجذور والصيغ والحقول يتغيّر مع المراجعات. احسبه من الملفّ وقت البناء، ولا تكتبه في الشيفرة ولا في الواجهة نصًّا ثابتًا. |
| نوعان من العدّ | مجموع الورود (بالتكرار) غير عدد الصيغ الفريدة. سمِّ كلًّا باسمه في الواجهة. |
| نصّ القرءان كما هو | اعرض `quran-full.json` حرفيًّا: لا تحذف تشكيلًا ولا رسمًا عثمانيًّا، ولا تقطع آية بلا علامة. للمطابقة والبحث ابنِ مفتاحًا مطبَّعًا منفصلًا، ولا تعرضه نصًّا قرءانيًّا. |
| رواية واحدة | البيانات على رواية حفص وعدّها (6236 آية). لا تخلطها بمصدرٍ بعدٍّ آخر دون تحويل المراجع. |
| خطٌّ قرءانيّ | الرسم العثمانيّ يحتاج خطًّا يدعمه (خطّ حفص من مجمع الملك فهد مثلًا)، لا خطًّا عربيًّا عامًّا. |
| لا خلط مصادر | لا تعرض تفسيرًا أو معنًى معجميًّا خارجيًّا بجانب تحليل قَولات باسمها. افصل المصدرين وسمِّ كلًّا. |
| حداثة البيانات | الملفّات تُحدَّث مع كلّ مراجعة. أعد التنزيل عند كلّ إصدارٍ من تطبيقك، وقارن `Last-Modified` أو تاريخ `/resources/`. |
| ليست فتوى | التحليل لغويّ داخليّ، لا حكم فقهيّ. لا تقدّمه في الواجهة على أنّه فتوى. |

## النسبة (شرط الرخصة)

ضع في واجهة التطبيق أو صفحة «حول» أو ملفّ README:

> قَولات — موسوعة جذور القرءان. بيانات مفتوحة برخصة CC BY 4.0. https://qawlat.com/resources/

والتعديل مباح بشرط ذكر أنّ البيانات عُدِّلت.

## بعد البناء

- تحقّق آليًّا أنّ كلّ نصّ آيةٍ معروض يطابق `quran-full.json` حرفًا حرفًا، في الاختبارات لا يدويًّا.
- لأسئلة المستخدمين الحرّة استعمل أدوات MCP (مهارة `qawlat`) بدل تأليف الإجابة من الملفّات.
