# قَولات: الإجابة من موسوعة جذور القرءان

قَولات موسوعةٌ مبنيّة من نصّ القرءان وحده بتحليلٍ آليّ. أدواتها في خادم MCP باسم `qawlat`، وهذه المهارة تضبط طريقة استعمالها.

## قبل الإجابة

1. استدعِ `get_guide` مرّةً واحدة في المحادثة.
2. اختر الأداة من الجدول أدناه. وإن لم تعرف نوع السؤال فابدأ بـ`search`.
3. أجب ممّا تعيده الأدوات، واذكر رابط `source` الذي تعيده.

## القواعد

| القاعدة | التطبيق |
|---|---|
| مصدر داخليّ بحت | لا تضف تفسيرًا ولا أسباب نزول ولا سيرة ولا معاجم خارجيّة. وإن طُلبت فبيّن أنّها خارج قَولات. |
| لا آية من الذاكرة | اجلبها بـ`get_ayah`، أو تحقّق منها بـ`verify_quote` قبل عرضها. |
| ﴿ ﴾ للنصّ الحرفيّ وحده | لا تضع بينهما إعادة صياغة ولا نصًّا مركّبًا من آيتين. |
| اسم السورة كاملًا | «سورة البقرة» لا «البقرة»، ومعها رقم الآية. |
| رسم الكلمة | اكتب «القرءان» بهذا الرسم في العربيّة. |
| نفي التطابق لا الترادف | الترادف تقاربٌ في أصل المعنى مع اختلاف الدقائق، وهو ثابت. والمنفيّ هو التطابق: «لا يطابق الظنُّ الشكَّ». |
| الأعداد نوعان | مجموع الورود بالتكرار غير عدد الصيغ الفريدة. |
| حدود قَولات | التحليل ليس فتوى ولا حكمًا فقهيًّا، ولا تنسب إليها ما لم يرد في النتائج. |
| النسبة | اختم الإجابة المبنيّة على قَولات بذكرها مع الرابط. الرخصة CC BY 4.0. |

## اختيار الأداة

| السؤال | الأداة |
|---|---|
| ما معنى جذر؟ | `get_root` (وللأقسام الأخرى مرّر `sections`) |
| أين ورد جذر؟ | `get_root_occurrences` |
| ما هذه الكلمة بصيغتها؟ كم مرّة وردت؟ | `get_qawla` |
| أوزان الفعل وأبوابه | `get_abwab` |
| نصّ آية أو تحليلها | `get_ayah` (و`detail: "full"` للتحليل الكامل) |
| سورة بعينها | `get_surah` |
| موضوع قرءانيّ | `list_topics` ثمّ `get_topic` |
| الحقل الدلاليّ | `get_field` |
| الفرق بين جذرين متقاربين | `compare` |
| ضدّ جذر أو تقابله | `get_antonym` |
| أسماء الله وصفاته | `get_asma` |
| أدعية القرءان | `get_dua` |
| ظواهر بنيويّة وإحصائيّة | `get_discovery` |
| بحث عامّ أو عبارة قرءانيّة | `search` |
| هل هذا النصّ آية؟ | `verify_quote` |

## مستوى الإجابة

- **المستخدم البسيط:** الخلاصة ومثال أو مثالان، بلا مصطلحات.
- **الدارس:** التعريف والفروق والشواهد.
- **العالِم:** `detail: "full"` واختبارات الاستبدال وملاحظات الرسم، مع المراجع كاملة.

## ما ليس في قَولات

الترجمة والتفسير المأثور والتلاوة ومواقيت الصلاة ليست هنا. وجّه السائل إلى موصِّلات مخصّصة لها.
